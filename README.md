# ServicePay

Учебный интернет-магазин услуг по оплате цифровых сервисов. Проект продолжает практическую работу № 1 по организации разработки в Kaiten.

## Реализованный этап

Начата разработка клиентской части: создан прототип каталога услуг.

- Четыре демонстрационные услуги с описанием и ценой.
- Поиск по названию без учёта регистра, сообщение при отсутствии результатов.
- Выбор услуги и подписки на 1, 3 или 12 месяцев.
- Расчёт стоимости с комиссией 10%.
- Создание демозаявки на странице без отправки данных.
- Адаптивное оформление для телефона и компьютера.

Названия и цены вымышлены. Реальная оплата, авторизация, база данных и серверная часть не реализованы. Этап разработки в целом остаётся в работе.

## Запуск

Открыть `index.html` в современном браузере. Установка зависимостей и сервер не требуются.

## Структура

- `index.html` — разметка каталога и расчёта заказа.
- `style.css` — оформление и адаптивная сетка.
- `app.js` — демонстрационные данные, поиск, выбор услуги, расчёт.
- `tests/calculation.test.cjs` — автоматические проверки расчёта.
- `tests/test-cases.md` — сценарии ручного тестирования.

## Проверки

При установленном Node.js выполнить из папки проекта:

```sh
node --test tests/calculation.test.cjs
```

## Ветви и Kaiten

Ветви проекта: `main` — основная версия прототипа, `dev` — разработка, `tests` — проверки. Начальная версия каталога размещена во всех трёх ветвях.

В карточке разработки клиентской части можно отметить «Создан прототип каталога услуг» и приложить ссылку на коммит. Статус этапа — «В работе». Следующие задачи: серверное API, хранение заказов и авторизация.
